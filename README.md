# dirSummary - フォルダ解析アシスタント

このツールは、Windows の `dir` コマンドで取得したフォルダ構成を OpenAI API に渡し、  
**フォルダの用途や特徴を自動で要約してくれるアプリ** です。  
読み取り専用でファイルの中身には一切アクセスせず要約します。

---

## 📦 機能

- 任意のフォルダパスを指定して解析
- サブフォルダを含めた `dir /s` に対応
- 出力が大きい場合は「分割ブロック」ごとに整理 → 最後に統合要約
- 入力が空なら **カレントディレクトリを自動解析**
- 結果は文章ベースで出力（安全・シンプル）

---

## 🚀 使い方

### 1. インストール

```
pip install openai
````

### 2. APIキー設定

OpenAI API キーをシステム環境変数に登録してください。

#### Windows (PowerShell)

```
setx OPENAI_API_KEY "sk-xxxxxx"
```
※システム環境変数からでも良い。

#### macOS / Linux

```
export OPENAI_API_KEY="sk-xxxxxx"
```

---

### 3. 実行方法

```
python dirSummary.py
```

起動すると、解析したいフォルダのパスを入力できます。

例:

```
フォルダパス: C:\Users\YourName\Documents
```

何も入力せずに Enter を押すと、現在のフォルダを解析します。

---

## 📊 出力イメージ（print文）

```
=== 分割ブロック 1/5 の要約 ===
この部分には Word 文書と PDF が多く含まれており、会議資料用のフォルダと推測される。

=== 分割ブロック 2/5 の要約 ===
ソースコード (.py ファイル) が中心。開発用のサブディレクトリ。

...

=== フォルダ全体の最終要約 ===
このフォルダは、ソフトウェア開発プロジェクトのリポジトリであり、
ドキュメントと成果物を合わせて管理している。
```

---

## 注意点

* **ファイル内容は一切読みません** → 上書き・削除の心配はありません
* 大規模フォルダを解析するときは **分割ブロック** が多数になるため、API利用料に注意
* OpenAI API の制限（TPM/RPM）にかかる場合は少し待って再実行してください
